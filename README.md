# Pruebas-hubspot-api

## Descripción

Este proyecto conecta tu cuenta de **HubSpot** con una base de datos para **traer la información**, **ordenarla** y **mostrarla en gráficos claros** que ayuden a tomar decisiones.

### ¿Qué haremos, paso a paso?
1. **Conexión a HubSpot (solo lectura):** nos autorizas el acceso y descargamos datos como contactos, empresas y negocios, sin modificar nada en tu cuenta.
2. **Extracción de datos:** copiamos la información a un lugar centralizado para tener “una sola versión de la verdad”.
3. **Limpieza y orden:** corregimos errores comunes (por ejemplo, emails con mayúsculas o espacios), unificamos formatos (teléfonos, fechas) y eliminamos duplicados.
4. **Organización útil:** clasificamos la información por categorías y períodos de tiempo para que sea fácil buscar, filtrar y comparar.
5. **Visualización sencilla:** creamos paneles con gráficos y tablas para ver tendencias, resultados por mes, desempeño del equipo y estado del embudo de ventas.
6. **Actualizaciones periódicas:** programamos una rutina para mantener los datos al día sin que tengas que hacerlo manualmente.

### ¿Qué obtendrás?
- **Paneles visuales** que muestran lo importante de un vistazo.
- **Datos limpios y consistentes** para evitar confusiones.
- **Reportes listos** para compartir con tu equipo y apoyar decisiones rápidas.
